## 1. The contract and the catalog

- [x] 1.1 `conformance/rendering/contract.py`: the four criteria (*Contained*,
  *Whole*, *One size*, *Aligned*), the optical-size formula (the geometric
  mean of the ink box's sides, in cell heights, after the build's
  normalisation) and the ±15% cap.
  It names no terminal and no font.
- [x] 1.2 `conformance/rendering/fonts.json`: JetBrains Mono, Fira Code,
  Hack, Iosevka, Caskaydia, Meslo and Symbols-only, each in its plain, Mono

  release, and give each file its URL and sha256. A fetch script verifies
  every digest and fails on a mismatch.
- [x] 1.3 Pin the Nerd Fonts `glyphnames.json` of the same release beside
  the catalog, by digest.

## 7. Measure, then calibrate

- [x] 7.1 The "before" run: this tree built with the old `nerd.json`
  (`lab.py --uze`), every terminal, JetBrains Mono and Fira Code in all
  three builds. Result: **47 of 48 cases failed** *One size*. The plain and
  Propo builds named `architect`, `code`, `mark.failed` and `task.ready`.
  The Mono builds named `changes`, or the check marks. That is the
  reported "large here, small there", in every terminal. There were no
  collisions: every surface already leaves the cell after an icon blank.
- [x] 7.2 Full run: 8 terminals × 20 fonts (7 families; plain, Mono and
  Propo where shipped).
- [x] 7.3 The first full run: 157 of 160. The three failures were the
  Symbols-only fallback in WezTerm and Ghostty, which rescale a fallback's
  icons per icon. `mark.sparkle` and `file.config` are recorded in
  `nerd_set.LAB_REJECTED` with what the Lab saw. The generator then moved
  `file.data` to Font Awesome's database and `code` to Codicons' `{}` to
  hold the band. Final run: **160 of 160**. Every verdict reproduces from
  its screenshot (`replay`).
- [x] 7.4 ~~Compare U+0020 with U+00A0 as the gutter~~. Dropped: every
  surface already draws a plain space, and a second kind of blank would
  fight the terminals whose enlarging makes the builds look alike (design,
  "The gutter is a plain space").
- [ ] 7.5 Manual evidence for Windows Terminal on this machine, and for
  Terminal.app and iTerm2 through `macos-session.yml`. Each is a
  screenshot of `uze theme specimen nerd` measured by `analyze.py` into
  `evidence/manual/`.
- [x] 7.6 Write `evidence/catalog.json` from the runs.
