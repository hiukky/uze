Two choices, made apart: the **theme** (colours) and the **icons** (the glyphs
uze draws its marks with). Both apply to the workspace and the CLI at once, and
both are also under management (`Ctrl+O`), where `t` opens the theme picker.

## Theme

```bash
uze config theme list          # the themes you can use
uze config theme set dracula   # use one
```

Built in: `default`, `dracula`, `catppuccin-mocha`, `tokyo-night` and
`tokyo-night-light`. You can also [write your own](/docs/advanced/themes).

## Icons

**Install a [Nerd Font](https://www.nerdfonts.com/font-downloads)** (the *Mono*
build, v3 or newer), set it as your terminal's font, then:

```bash
uze config icons nerd
```

Without one, the `default` set uses plain Unicode and works everywhere, though
some fonts draw its marks unevenly. `ascii` is for consoles with no Unicode at
all.

```bash
uze config icons    # each set drawn in its own glyphs: pick the one that looks right
```
