**uze is one setup for every coding agent.** Run Claude Code, Codex, OpenCode
and Antigravity side by side, each in a checkout of its own, and give all of
them the same plugins and the same project instructions.

<Demo
  src="/uze-demo.gif"
  poster="/uze-demo-poster.png"
  alt="The uze workspace: several agents at once, each on its own branch in its own checkout."
/>

It does two things.

**It runs your agents.** `uze` opens a terminal workspace where every agent gets
a tab, a branch and, if you want, a checkout of its own. You see what each one
changed, and bring the work home when it is ready.
[The workspace →](/docs/workspace)

**It delivers your tooling.** Install a plugin once and every agent receives it
through its own native mechanism. Write one `AGENTS.md` and every agent reads
it. [Plugins →](/docs/plugins)

<Callout type="info">
  uze is **alpha**. Commands and file formats may still change before v1.
</Callout>
