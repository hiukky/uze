## Set up your agents

```bash
uze setup
```

uze finds the coding agents on your machine and offers to install the missing
ones through each vendor's official installer. Pick the ones you use. Running
`uze` for the first time asks the same question.

```bash
uze setup list    # what is installed and ready
```

## Staying current

uze updates itself. The workspace checks for a new release when it opens and
every hour after, and tells you when one is installed; restart to use it.
`uze upgrade` does the same on demand.

## Removing uze

1. Take every plugin off your agents, while uze is still here:

   ```bash
   uze status -m          # the plugins on this machine
   uze remove <plugin> -m # once per plugin
   ```

2. Stop the workspace in each project where you opened it: `uze terminal stop`.
3. In each project, delete `agents.yaml`, `agents.lock` and `.worktrees/` if you
   no longer want them, and the `uze:begin … uze:end` blocks in `AGENTS.md`.
4. Delete the `# >>> uze shims path >>>` block from your shell's rc file.
5. Delete the binary and uze's home:

   ```bash
   rm ~/.local/bin/uze
   rm -rf ~/.uze
   ```

The agents themselves stay installed; remove them the way their vendor says.
