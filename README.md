# CLA signatures

This branch holds nothing but the record of who has signed
[`CLA.md`](../../blob/main/CLA.md), written by the CLA workflow at
`signatures/v1/cla.json`.

It is an orphan branch: it shares no history with `main`, is never merged
into it, and carries no code. Signing a contributor agreement should not put
a commit in the history of the project you are contributing to.

`v1` is the version of the document that was signed. If `CLA.md` ever changes
in a way that changes what a signature means, the path becomes `v2` and
everyone signs again — nobody stays recorded as having agreed to a document
they never read.

Each entry is the contributor's GitHub login and id, the pull request the
signature was given on, and when. All of it is already public.
