Antigravity — gets it through its own most native surface.

## Quick start

```bash
curl -fsSL https://hiukky.com/uze/install.sh | sh
uze setup              # detect + provision harnesses
uze flow@ai            # add a plugin from a marketplace to this project
```

Prefer building from source during alpha? `cargo install --path .`.

`uze doctor`, `uze status` and `uze context reconcile` are the next step —
see `uze --help` or run `uze` for the terminal UI.

## Why uze

- **One install, one context, every harness** — canonical plugin bytes and
  `AGENTS.md` live once; uze projects them natively per harness.
- **Managed lifecycle** — typed receipts, drift detection, ownership checks;
  nothing is silently overwritten; removal inspects before detaching.
- **Evidence-graded** — deterministic suite (`tests/`) + real-harness lab
  (`conformance/`), per-harness evidence, plus the `plugins/uze` marketplace
  and a terminal UI (`uze`).

APIs, schemas and harness integration behavior may change while the
cross-harness model is being validated. Real-harness evidence for the
primary V0 set lives in [`conformance/README.md`](conformance/README.md);
architecture decisions and invariants in [`docs/`](docs/adr/README.md).
